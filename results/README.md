# Resultados

Solo se versionarán resultados seleccionados que respalden el notebook o la presentación:

- `figures/`: curvas y visualizaciones finales;
- `tables/`: tablas comparativas finales.

Ejecuciones completas, modelos, checkpoints y salidas voluminosas permanecen locales en directorios ignorados por Git. Ninguna figura o tabla seleccionada debe publicarse sin identificar el experimento y la configuración que la produjo.
